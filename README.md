# DP FITNESS

A premium, responsive single-page gym website concept for **DP Fitness**, a fictional fitness brand based in Pune. Built with semantic HTML, custom CSS, Bootstrap 5, Bootstrap Icons, and vanilla JavaScript.

## Features

- Dark charcoal and electric-lime visual theme with responsive layouts.
- Sticky navigation with a mobile menu and scroll state.
- Hero, about, programs, benefits, trainers, memberships, testimonials, CTA, contact, and footer sections.
- Scroll-triggered reveals, animated statistics, and a functional testimonial carousel.
- Enquiry form with client-side validation and demo-only success feedback. It does **not** send or store submissions.
- Keyboard-friendly navigation, accessible labels, reduced-motion support, and descriptive image alternatives.

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve the project directory with a local static server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

The page loads Bootstrap, Bootstrap Icons, Google Fonts, and photography from external CDNs. An internet connection is needed to load those assets.
